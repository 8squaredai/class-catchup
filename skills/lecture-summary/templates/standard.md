# Template: Standard catch-up 📘

The default for a normal lecture: what was taught, what changed, what to do next.

## `markdown` (roughly 300–600 words for a 60–90 minute class, plus add-ons)

```
# <Course code>: <lecture title> (<date>)

**In one sentence:** <what this session was about>

## Announcements
- ... [mm:ss]

## What was covered
### <Topic 1>
- ... [mm:ss]
### <Topic 2>
- ... [mm:ss]

## Before next class
- <what to review, read or do, only if the professor said it> [mm:ss]
```

- Announcements: only items that change what the student must do (deadlines, exams, assignment
  changes, readings, room/time changes). If none, write "No announcements in this session."
- What was covered: 2–5 topics in the order taught, 2–4 specific bullets each.
- Omit "Before next class" if the professor gave nothing to do.

## `whatsapp_text` (under 1,200 characters)

```
📚 *<Course code> – <lecture title>* (<date>)
You missed class. Here's what happened:

⚠️ *Announcements*
• ... [mm:ss]

🧠 *Key points*
• ... [mm:ss]
(3–5 bullets, each a complete idea with its actual content)

✅ *Before next class*
• ... [mm:ss]

💬 Reply with any question about this class and I'll answer from the recording.
```

Leave out the Announcements or Before-next-class block when empty.
