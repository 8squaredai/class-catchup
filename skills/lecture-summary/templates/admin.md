# Template: Admin only 📋

For sessions that were mostly logistics. Only what the student must know or do; content gets
one line.

## `markdown` (plus add-ons)

```
# <Course code>: <lecture title> (<date>)

**Content covered:** <one sentence>

## Deadlines & dates
- ... [mm:ss]

## Readings & materials
- ... [mm:ss]

## Assignments & grading
- ... [mm:ss]

## Logistics
- <room, time, office hours, format or team changes> [mm:ss]
```

Omit every empty section. If there was nothing administrative at all, write
"No administrative announcements in this session." under the content line.

## `whatsapp_text` (under 700 characters)

```
📋 *<Course code> – <lecture title>* (<date>)
Admin update from the class you missed:

📅 ... [mm:ss]
📖 ... [mm:ss]
📝 ... [mm:ss]
🏫 ... [mm:ss]

💬 Reply with any question about this class and I'll answer from the recording.
```

Use 📅 for deadlines and dates, 📖 readings and materials, 📝 assignments and grading, 🏫 logistics.
Only include lines that have content.
