# Template: Quick recap ⚡

For a light session where nothing critical happened. The student should be done in 20 seconds.

## `markdown` (max ~150 words plus add-ons)

```
# <Course code>: <lecture title> (<date>)

**In one sentence:** <what this session was about>

## The 3 things to know
- ... [mm:ss]
- ... [mm:ss]
- ... [mm:ss]

## Deadlines & to-dos
- ... [mm:ss]
```

Exactly three bullets under "The 3 things to know" (fewer only if the session had less).
Omit "Deadlines & to-dos" if there were none.

⚡ *<Course code> – <lecture title>* (<date>)
Light session, here's all you need:
• ... [mm:ss]
• ... [mm:ss]
• ... [mm:ss]
