# Template: Study guide 🎓

For exam-relevant material. The student should be able to learn the content from this page.

## `markdown` (roughly 500–900 words, plus add-ons)

```
# <Course code>: <lecture title> (<date>)

**In one sentence:** <what this session was about>

## Key concepts
### <Concept 1>
- **In the professor's words:** <close paraphrase or short quote> [mm:ss]
- **Example from class:** ... [mm:ss]
- **Why it matters:** ... [mm:ss]

## Flagged as important
- "<what the professor said>": <what it refers to> [mm:ss]

## How the ideas connect
- ... [mm:ss]

## Deadlines
- ... [mm:ss]
```

- Key concepts: 3–7 concepts in the order taught. "Example from class" and "Why it matters"
  only when the professor gave them; never make up an example.
- Flagged as important: only where the professor signalled it ("this will be on the exam",
  "remember this", "the key idea", repeated emphasis). Quote the signal. If none, write
  "The professor did not flag anything as exam material in this session."
- How the ideas connect: 2–4 bullets, only connections the professor made. Omit otherwise.
- Omit "Deadlines" if there were none.

## `whatsapp_text` (under 1,500 characters)

```
🎓 *<Course code> – <lecture title>* (<date>)
Study guide for the class you missed:

📌 *Core ideas*
• *<Concept>*: <one-line definition as the professor gave it> [mm:ss]
(3–5 bullets)

🚩 *Flagged as important*
• ... [mm:ss]

📄 The full study guide (examples and more) is on the page below.

💬 Reply with any question about this class and I'll answer from the recording.
```

Leave out the 🚩 block if nothing was flagged.
